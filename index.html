qr_code_2 Barcode Thermal Printer (TSC TL240)

Configure dedicated silent thermal printing for 2 × 1-inch labels (50.8 × 25.4 mm). Jobs will be submitted silently to the configured TSC TL240 printer without showing a print dialog.

Client Windows Printer Setup Checklist:
1. In Windows Settings > Printers & Scanners > TSC TL240 > Printing Preferences:
   • Set Paper Size / Stock to 2.00 in × 1.00 in (50.8 × 25.4 mm).
   • Set Media Type to Die-Cut Label with Gaps (Transmissive Sensor) with 2-3 mm gap.
   • Set Print Speed to 3.0 or 4.0 ips, Darkness/Density to 8-10.
2. When Print Barcodes is clicked in thermal mode, jobs are sent silently to this device without dialogs.
